# Guía de Contribución — Andina Market 360

1. **Ramas:** Nunca edite `main` directamente. Cree ramas con prefijo `feature/`, `fix/` o `docs/`.
2. **Commits:** Utilice mensajes claros y atómicos (ej. `feat: agregar filtro por sede`).
3. **Pruebas:** Todo Pull Request debe aprobar `python -m unittest discover -s tests -v`.
4. **Privacidad:** Prohibido subir contraseñas, tokens, claves privadas o datos reales de personas.
