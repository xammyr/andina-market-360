Especializado/a en control de versiones con Git/GitHub, análisis de datos con Python y despliegues estáticos automatizados.

## 🚀 Proyectos destacados

### 🛒 1. [Andina Market 360](https://github.com/USUARIO/andina-market-360)
- **Problema:** Consolidar ventas dispersas de 3 sedes (Lima, Ica, Arequipa) sin errores manuales.
- **Solución:** Procesamiento de datos en Python (`resumen.py`), 4 pruebas unitarias automatizadas (`unittest`), y publicación del resumen en GitHub Pages.
- **Tecnologías:** Python 3, Git, GitHub Actions, HTML/CSS.

### 📊 2. [Monitor de Ventas e Inventario](https://github.com/USUARIO/monitor-inventario-demo)
- **Problema:** Trazabilidad de stock y alerta de reposición temprana para pequeños comercios.
- **Solución:** Flujo de trabajo en ramas (`Git Flow`), integración continua y reportes en Markdown.
- **Tecnologías:** Python, Markdown, GitHub Projects.
